# ShopTest Playwright E2E — partial starter

**Status: partial starter, not complete Admin/Seller/Customer coverage.** Public page objects and smoke tests exist, together with role-login setup and a storage-state validator. Protected role pages and end-to-end commerce flows are not implemented because the interactive application/browser environment could not be reached. See [`FEATURE-INVENTORY.md`](FEATURE-INVENTORY.md) for the evidence and gaps.

## Configure

```sh
npm ci
cp .env.example .env
```

`.env.example` contains the app's documented seeded demo credentials. Tests read credentials only from `.env`/the process environment; they are not embedded in test code. `auth/admin.json`, `auth/seller.json`, and `auth/customer.json` are generated by the setup tests and ignored by Git. Empty storage state is explicitly rejected.

## Run in a browser-enabled environment

```sh
npx playwright install chromium webkit
npx playwright test --list
npx playwright test
npx playwright test --headed
npx playwright test --debug
npx playwright show-report
```

Public-only checks can be selected with `npx playwright test --project=desktop-public`; they still require a working Chromium installation and network access to `BASE_URL`. The `admin`, `seller`, and `customer` projects depend on the setup project and their individual storage-state files.
